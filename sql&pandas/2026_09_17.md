## SQL 解答
```SQL
# 1 窗口函数 ROW_NUMBER()
select round(
    avg(
        case
            when order_date = customer_pref_delivery_date
            then 1
            else 0
        end
    )* 100 ,2) as immediate_percentage
from (
    select
        *,
        ROW_NUMBER() over(
            partition by customer_id
            order by order_date ASC
        ) as rn
    from delivery
) as a
where rn = 1; 
```
1.`ROW_NUMBER()` 语法
ROW_NUMBER() 是一个窗口排名函数（Window Ranking Function），它的作用是按照指定顺序，给数据中的每一行分配一个从 1 开始的连续编号。  
它在数据分析中非常常见，尤其适用于：获取**每个用户最新的一笔交易、每个部门工资最高的员工、每个用户的第一次申请**等。  
```SQL
#例如
ROW_NUMBER() OVER (
    PARTITION BY 分组字段
    ORDER BY 排序字段 DESC
)
```
例子：假设存在交易表 Transactions：  
| txn_id | user_id | amount |
| :---: | :---: | :---: |
| 101 | A | 500 |
| 102 | A | 800 |
| 103 | A | 300 |
| 201 | B | 700 |
| 202 | B | 900 |
| 301 | C | 400 |

### 1.1 现在要求：按照交易金额，从大到小给所有交易编号。
```SQL
SELECT
    txn_id,
    user_id,
    amount,
    ROW_NUMBER() OVER (
        ORDER BY amount DESC
    ) AS rn
FROM Transactions;
```
则会变成下面的结果
| txn_id | user_id | amount | rn |
| :---: | :---: | :---: | :---: |
| 202    | B       | 900    | 1  |
| 102    | A       | 800    | 2  |
| 201    | B       | 700    | 3  |
| 101    | A       | 500    | 4  |
| 301    | C       | 400    | 5  |
| 103    | A       | 300    | 6  |

- 按照 `amount desc` 排序
- 未分组  

### 1.2 加入 PARTITION BY
```sql
SELECT
    txn_id,
    user_id,
    amount,
    ROW_NUMBER() OVER (
        PARTITION BY user_id
        ORDER BY amount DESC
    ) AS rn
FROM Transactions
ORDER BY user_id, rn;
```
`PARTITION BY user_id`则会得到三个窗口：
| txn_id | amount |
| :---: | :---: |
| 101 | 500
| 102 | 800
| 103 | 300

| txn_id | amount |
| :---: | :---: |
201|700
202|900

| txn_id | amount |
| :---: | :---: |
301|400

继续`ORDER BY amount DESC`,`ROW_NUMBER()`则会：
| txn_id | user_id | amount | rn |
| :---: | :---: | :---: | :---: |
A|102|800|1
| A       | 101    | 500    | 2  |
| A       | 103    | 300    | 3  |
| B       | 202    | 900    | 1  |
| B       | 201    | 700    | 2  |
| C       | 301    | 400    | 1  |

### 1.3 ROW_NUMBER() 和 GROUP BY 有什么区别？  
`GROUP BY` 会将相同分组键的多行数据汇总为一行，改变数据粒度；  
`PARTITION BY` 只划分窗口函数的计算范围，不会合并原始记录。  

例如，1000 笔交易涉及 100 个客户，按 `user_id GROUP BY` 汇总后得到 100 行；使用 `SUM(amount) OVER (PARTITION BY user_id)` 则仍保留 1000 行，只是在每笔交易旁边增加该客户的交易总金额。

### 1.4 业务实战：获取每个用户最新的一笔交易
假设有以下数据：
| txn_id | user_id | trans_date | amount |
|--------|---------|------------|--------|
| 101    | A       | 2026-09-01 | 500    |
| 102    | A       | 2026-09-10 | 800    |
| 103    | A       | 2026-09-15 | 300    |
| 201    | B       | 2026-09-02 | 700    |
| 202    | B       | 2026-09-12 | 900    |
| 301    | C       | 2026-09-03 | 400    |

**要使用 CTE 进行筛选**：
```sql
WITH ranked AS (
    SELECT
        txn_id,
        user_id,
        trans_date,
        amount,
        ROW_NUMBER() OVER (
            PARTITION BY user_id
            ORDER BY trans_date DESC, txn_id DESC
        ) AS rn
    FROM Transactions
)

SELECT
    user_id,
    txn_id,
    amount
FROM ranked
WHERE rn = 1;
```
因为 WHERE 过滤发生在窗口函数计算之前，不能直接在同一查询层级的 WHERE 中引用刚刚产生的 rn。

所以需要使用 CTE 或子查询，先生成编号，再在外层筛选。

## pandas解答
```python
import pandas as pd

def immediate_food_delivery(delivery: pd.DataFrame) -> pd.DataFrame:

    # 1.排序
    sorted_data = delivery.sort_values(
        ['customer_id'], ['order_date']
    )

    # 2.给每个客户的订单编号
    sorted_data['rn'] = (
        sorted_data.groupby('customer_id').cumcount() + 1
    )

    # 3.只保留每个客户的第一笔订单
    first_orders = sorted_data[sorted_data['rn'] == 1]

    # 4.判断是否为即时配送
    condition = (
        first_orders['order_date']
        == first_orders['customer_pref_delivery_date']
    )

    # 5.计算百分比
    percentage = round(condition.mean()*100, 2)

    # 6.构造结果 DataFrame
    result = pd.DataFrame({
        'immediate_percentage': [percentage]
    })

    return result
```
