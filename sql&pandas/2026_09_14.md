# 570.至少有五名直接下属的经理--复习次数：
https://leetcode.cn/problems/managers-with-at-least-5-direct-reports/description/?envType=study-plan-v2&envId=sql-free-50 \
\
SQL 解答
```SQL
select name
from employee
where id in (
    select managerId
    from Employee
    group by managerId
    having count(managerId) >= 5
);
```
Pandas 解答
```Python
import pandas as pd

def find_managers(employee: pd.DataFrame) -> pd.DataFrame:
    grouped = employee.groupby('managerId') #groupby
    manager_count = grouped.size()
    qualified = manager_count[manager_count >= 5] #having count()
    manager_ids = qualified.index
    condition = employee['id'].isin(manager_ids) #where
    filtered = employee
    result = filtered[['name']]
    return result

# .index用法讲解：
# 其作用，就是把 Pandas 对象左边那一排“行标签”取出来。

# 在这道题里，employee.groupby('managerId').size() 之后，managerId 不再是普通列，而变成了**结果的索引**
# 筛选出人数 >=5 后，我们真正需要的是符合条件的经理编号（结果的索引），而不是人数，所以要写 qualified.index

# 本质上就一个问题：想要的数据是不是存放在行标签里；如果是，就用 .index
```
