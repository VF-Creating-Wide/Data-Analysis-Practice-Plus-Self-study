# 1193.每月交易--复习次数：
https://leetcode.cn/problems/monthly-transactions-i/submissions/749582353/?envType=study-plan-v2&envId=sql-free-50 \
\
SQL 解答
```SQL
select date_format(trans_date, '%Y-%m') as month,
country,
count(*) as trans_count,
sum(if(state = 'approved', 1, 0)) as approved_count,
sum(amount) as trans_total_amount,
sum(if(state = 'approved', amount, 0)) as approved_total_amount
from Transactions
group by month, country
```
1. `date_format(--, '%Y-%m')` 日期格式化函数语法 \
\
此题不用 `month(--)` 是因为 `month(--)` 直接输出月份数字 \
而 `date_format(--, '%Y-%m')` 会输出 XXXX - XX \
除此之外要注意 `date_format(--, '%Y-%m')` 年份字母大写 \
其 ‘日期’ 写法为 `date_format(--, '%Y-%m-%d')` 
2. `if()`函数 \
\ 
`if()`在此题目中可以有两种写法 \
在统计`approved_count`是，可以用 `sum(if(state = 'approved', 1, 0))` 统计**数字** \
也可以用 `count(if(state = 'approved', 1, null))` 统计**账户个数**
