SQL 解答
```SQL
# 1 窗口函数 ROW_NUMBER()
select round(
    avg(
        case
            when order_date = customer_pref_delivery_date
            then 1
            else 0
        end
    )* 100 ,2) as immediate_percentage
from (
    select
        *,
        ROW_NUMBER() over(
            partition by customer_id
            order by order_date ASC
        ) as rn
    from delivery
) as a
where rn = 1; 
```
1.`ROW_NUMBER()` 语法
ROW_NUMBER() 是一个窗口排名函数（Window Ranking Function），它的作用是按照指定顺序，给数据中的每一行分配一个从 1 开始的连续编号。  
它在数据分析中非常常见，尤其适用于：获取**每个用户最新的一笔交易、每个部门工资最高的员工、每个用户的第一次申请**等。  
```SQL
#例如
ROW_NUMBER() OVER (
    PARTITION BY 分组字段
    ORDER BY 排序字段 DESC
)
```

```python
import pandas as pd

def immediate_food_delivery(delivery: pd.DataFrame) -> pd.DataFrame:

    # 1.排序
    sorted_data = delivery.sort_values(
        ['customer_id'], ['order_date']
    )

    # 2.给每个客户的订单编号
    sorted_data['rn'] = (
        sorted_data.groupby('customer_id').cumcount() + 1
    )

    # 3.只保留每个客户的第一笔订单
    first_orders = sorted_data[sorted_data['rn'] == 1]

    # 4.判断是否为即时配送
    condition = (
        first_orders['order_date']
        == first_orders['customer_pref_delivery_date']
    )

    # 5.计算百分比
    percentage = round(condition.mean()*100, 2)

    # 6.构造结果 DataFrame
    result = pd.DataFrame({
        'immediate_percentage': [percentage]
    })

    return result
```
